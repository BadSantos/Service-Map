# Services Map

Services Map — веб-сервис для визуального мониторинга сервисов и дата-центров. Он помогает быстро увидеть размещение сервисов, связи между площадками, состояние инфраструктуры и зависимости между компонентами.

## Возможности

- интерактивная карта дата-центров и сервисных связей;
- просмотр состояния сервисов;
- отображение задержки, нагрузки и ошибок на сетевых связях;
- каталог сервисов, продуктов и внешних поставщиков;
- просмотр зависимостей между сервисами;
- фильтрация и поиск по каталогу;
- автономная работа без API-сервера и базы данных.

## Локальный запуск

Для запуска нужен Node.js 24 или новее и установленный `pnpm`.

Установите зависимости и запустите локальный dev-сервер:

```bash
pnpm install
pnpm run dev:local
```

Откройте приложение в браузере по адресу:

```text
http://127.0.0.1:5173
```

Эта команда использует локальный режим и не зависит от переменных Replit. Для запуска на другом порту можно использовать обычный Vite CLI или изменить команду в `package.json`.

```bash
pnpm run dev
```

Команда `pnpm run dev` также работает локально на `http://localhost:5173`, если переменная `PORT` не задана. В Replit она продолжает использовать порт, переданный workflow.

Не открывайте `index.html` напрямую через `file://`: приложение загружает `services-data.json` через `fetch`, поэтому ему нужен локальный HTTP-сервер.

Проверка production-сборки:

```bash
pnpm run build:local
pnpm run serve:local
```

После `pnpm run serve:local` приложение будет доступно на `http://127.0.0.1:4173`.

Перед коммитом запустите единую проверку:

```bash
pnpm run check
```

## Данные

Пример данных по сервисам и дата-центрам находится в файле `public/services-data.json`. По умолчанию приложение загружает этот файл через `fetch`.

Чтобы использовать внешний источник, скопируйте `.env.example` в `.env` и укажите:

```env
VITE_SERVICE_DATA_URL=https://example.test/services-data.json
```

Внешний сервер должен разрешать запросы из браузера через CORS и возвращать JSON той же структуры. Если переменная не задана, используется локальный snapshot.
